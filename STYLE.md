# Style Guide

Any change to the site's style (`assets/style.css`, `templates/`) must be recorded here.

1. **Element sizing is em based.** Use `em` (not `px`) for font sizes, logo/image dimensions and spacing, so everything scales from the body font size.
2. **Links are green.** Anchors use `--link` (`#3fb950`), not `--accent`, which stays amber for tags and other highlights.
